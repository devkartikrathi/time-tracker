# time-tracker

Monorepo for **Chronos**, a personal time tracker.

- [`fe/`](./fe) — the application (Next.js 16, React 19, Prisma 7, Clerk). See
  [`fe/README.md`](./fe/README.md) for setup.
- `be/` — a Go stub, currently unused. The application is served entirely from
  `fe/` via Next.js route handlers.
